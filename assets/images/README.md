# Restaurant Images

Add the real restaurant photos in this folder using the filenames in `js/script.js`.

Examples:

- `jollof-rice.jpg`
- `suya-skewers.jpg`
- `egusi-pounded-yam.jpg`
- `grilled-croaker.jpg`
- `chocolate-plantain-cake.jpg`
- `chilled-zobo.jpg`

The shared `menuDishes` data structure maps each filename to its dish. Replacing a photo does not require editing the HTML.
